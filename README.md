Система складского учёта

Учебный проект для практики, вариант 03.

Что сделано:

За первую неделю я сделал вёрстку сайта на HTML и CSS.
Добавил страницы товаров, складов, поставщиков, операций,
инвентаризации, отчётов и профиля.

Также сделал страницы входа, регистрации и администрирования.
На сайте есть примеры таблиц, форм и сообщений об ошибке,
загрузке, пустом списке и успешном действии.

Сайт можно посмотреть на компьютере и телефоне.

Как запустить:

1. Открыть папку проекта в VS Code.
2. Если расширение Live Server не установлено — установить его.
3. Нажать правой кнопкой мыши на файл `index.html`.
4. Выбрать Open with Live Server.

Также можно просто открыть `index.html` в браузере.
